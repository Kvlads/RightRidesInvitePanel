# Система заявок на мероприятия в экосистеме ВК

Цель - обеспечить участникам и гостям мероприятия возможность зарегистрироваться на мероприятие

## Задача

### Пользователь

Требуется реализовать платформу для сбора заявок от гостей и участников мероприятий
Заявки участников будут проходит модерацию посредством голосования в чате администраторов. Гостям голосование не требуется.

Регистрация гостей опциональна

После того, как администраторы проголосовали пользователю направляется уведомление о принятом решении
В случае положительного решения пользователю направляется информация о правилах участие, дате и времени заезда. (Текст редактируется по желанию)

По требованию администратора пользователям может быть направлена дополнительная рассылка с дополнительной информацией

### Администратор

Доступ в админ панель выполняется из того же приложения, где пользователь выполняет регистрацию

Основные возможности:

1. Создать мероприятие
2. Просмотреть список мероприятий
2.1 Редактировать
2.2 Удалить
2.3 Выполнить отправку уведомлений гостям\участникам или сразу всем

## Реализация

### План

Решено испоьзовать связку: ВК мини-приложение + вк бот

1. Приложение
1.1 Выполняет сбор заявок, функции администрирования
1.2 Отображает пользователям статус их заявок

2. Вк бот
2.1 Управляет голосованием в чате администраторов
2.2 Отправляет пользователям уведомления

### Структура

1. Api - общее api. Отвечает за обработку данных и рассылку сообщений от имени бота
2. App - React.js приложение, которое работает в экосистеме mini-app

### Экраны мини-приложения

1. Пользователь
1.1 Список мероприятий -> из элемента списка переход на экран мероприятия
1.2 Описание мероприятия. Отображение данных мероприятия -> кнопки перехода на экран регистрации (гость и участник указывают те же данные. Только гостю не нужно прикреплять фото)
1.3 Регистрация гостя или участника. Пользователь заполняет необходимые данные, если участник - добавляет фото -> После регистрации тост о том, то заявка принята и возврат на главный экран
1.4 Список заявок. Открывается с экрана  мероприятия. Позволяет посмотреть заявку, отображает статус решения в случае отказа или принятия заявки. Гость автоматом аппрув

2. Администратор
1.1 Список мероприятий -> из элемента списка переход на экран мероприятия
1.2 Мероприятие. Позволяет редактировать информацию о мероприятии. Позволяет выполнить рассылку сообщений для гостей и/или участников

### Этапы реализации

1. Развернуть среду разработки.
1.1 Дев - Запуск бд в docker. Api и App запускаются консольными командами
1.2 Прод - Бд, api, app запускаются внутри докер-окружения (nginx для минимизации необходимости настроек со стороны сервера)

2. Mini-app + api.
2.0 Тестовая реализация разрешения на отправку сообщений от имени бота пользователю
2.1 Админ-режим: создание, редактирование, удаление МП
2.2 Пользовательский режим: Просмотр МП, создание заявок от мени гостя и участника

3. Система одобрения заявок
3.1 Отправка заявок в админский чат
3.2 Одобрение заявок администраторами
3.3 Отправка уведомлений о статусе заявок пользователям
3.4 Отображение заявок в мини-аппке
